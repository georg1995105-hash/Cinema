# Постоянная подпись Android

Начиная с версии 0.4.0, сборка поддерживает единую подпись для следующих выпусков. В публичный репозиторий **нельзя** загружать приватный ключ или пароль.

Секреты GitHub Actions:
- `ANDROID_KEYSTORE_BASE64` — Base64 содержимого файла `kino-release.p12` (без переносов строк).
- `ANDROID_KEYSTORE_PASSWORD` — пароль хранилища и ключа.
- `ANDROID_KEY_ALIAS` — `kino`.

Ключ RSA-3072 / PKCS12 создан 17 ноября 2026 года. В GitHub пока может отсутствовать секрет `ANDROID_KEYSTORE_BASE64`: тогда CI выполняет тесты, но НЕ публикует подписанный APK. Этот случай специально не замещается случайной отладочной подписью.

После настройки всех трёх секретов:
1. Запустить сборку ветки main.
2. Проверить `apksigner verify --print-certs` и контрольную сумму.
3. Опубликовать APK как стабильную версию и проверить обновление следующей версией под тем же ключом.
4. Проверить на планшете сохранение истории и зеркал при установке поверх предыдущей **стабильной** версии.

Старые отладочные APK v0.1–0.3.1 подписаны иным ключом. Использовать их как основание для обновления без удаления невозможно: это ограничение механизма подписи Android. Нельзя подменять приватные ключи или скрытно обходить проверку подписи.

Резервную копию `kino-release.p12` и пароль хранить вне публичного GitHub. Утеря ключа лишит возможности выпускать совместимые обновления.

# Сеть и встроенное подключение — будущий модуль

Запрос: поддержка пользовательских ссылок `vless://`, `hysteria2://` и `hy2://` прямо в видео-приложении.

## Техническое решение

Не создавать второй системный VPN по умолчанию. Android допускает только одно активное приложение с правом `VpnService`; переключение разрывает существующий VPN. Основной режим приложения — использовать уже работающую сеть устройства, включая Phantom VPN, если он включён.

Дополнительный режим после завершения каталога и воспроизведения: **прокси только для приложения**. Для него потребуется отдельно интегрировать и проверить совместимый с Android движок, например Xray-core (для поддерживаемых транспортов) или поддерживающий оба протокола sing-box/libbox, и направить через него **все** запросы каталога, изображений, ссылок, субтитров и медиаплеера. Нельзя считать поддержку VLESS и Hysteria2 реализованной только по наличию пункта меню.

При реализации:
1. Сначала изучить лицензию, жизненный цикл и архитектуры Android/ABI выбранного ядра.
2. Разделять сеть устройства и локальный прокси; не менять системный VPN и другие приложения.
3. Не принимать конфиги с отключённой проверкой TLS по умолчанию.
4. Хранить ключи и параметры локально, не отправлять их в GitHub или аналитику.
5. Иметь отключение и восстановление прямого подключения, чтобы ошибка прокси не блокировала приложение.
6. Измерить RAM, энергопотребление, старт, работу в фоне и устойчивость на реальном планшете.
7. Проверять фактическую передачу трафика всех компонентов через выбранный маршрут.

**Текущий статус:** не внедрено. В сборке нет скрытого ядра Xray/sing-box и нет работающего переключателя VLESS/Hysteria2. Не добавлять декоративный пункт, пока модуль не работает.

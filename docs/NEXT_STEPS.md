# Очередность работ

1. Создан Android-каркас; гостевой режим, локальная история, плеер и собственные зеркала реализованы.
2. В версии 0.4.0 добавлен браузер выбранного зеркала внутри приложения. Код прошёл CI, но версия ещё не опубликована: ожидается постоянная подпись.
3. Подключить постоянный ключ подписи через секрет GitHub Actions `ANDROID_KEYSTORE_BASE64`, не помещая ключ в публичный репозиторий. Пароль и псевдоним уже добавлены как секреты.
4. Собрать стабильный APK, проверить его сертификат и выпустить следующий APK с тем же сертификатом для проверки обновления поверх первой стабильной версии.
5. Протестировать открытие выбранного пользователем зеркала **на планшете**: сайт, каталог, страница фильма, воспроизведение. Результат определить по фактическому поведению, а не только по HTTP HEAD.
6. По результатам тестирования внедрить нативный каталог, поиск и доступные потоки с учётом условий источника; затем карточки, серии, озвучки и историю.
7. Не добавлять второе системное VPN-подключение. Прокси конкретно для приложения — только отдельный этап.

Нельзя выдавать тестовый WebView за полностью готовую нативную интеграцию каталога.

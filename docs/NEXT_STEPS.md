# План дальнейших работ

## Уже готово

- 0.4.0: постоянная Android-подпись, гостевой просмотр пользовательского зеркала, стабильный выпуск.
- 0.4.1: нативная сетка постеров из HTML выбранного зеркала, отдельная карточка фильма, тот же постоянный сертификат. CI, тесты, подпись и публикация APK прошли.

## Что проверять дальше

1. Установку 0.4.1 поверх 0.4.0 **без удаления локальных данных**.
2. Загрузку настоящих названий и постеров с выбранного зеркала на планшете через рабочий VPN. При ошибке исследовать DOM на устройстве.
3. Реальные URL и соответствие вкладок «Горячие», «Новинки», «В ожидании» и типов контента. Не показывать одну подборку под разными названиями.
4. Страницы каталога 2+ и производительность; избегать множества тяжёлых WebView.
5. Нативное описание фильма, сезоны, серии и доступные озвучки в рамках разрешений источника.
6. Видеоплеер для поддерживаемых потоков без нарушения ограничений и DRM.
7. Реальный поиск по каталогу и действие фильтров, а не только интерфейс.
8. Для новых APK сохранить сертификат 0.4.0 и проверять подпись и совместимость при каждом выпуске.

Не трогать инфраструктуру Phantom VPN ради этого приложения.

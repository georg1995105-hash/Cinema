# Следующие этапы

## Выполнено в 0.4.3

- Собственный AndroidX Media3/ExoPlayer вместо веб-страницы по кнопке «Смотреть».
- Служебная загрузка метаданных и доступных MP4/HLS-ссылок с выбранного зеркала; выбор озвучки, сезона, серии и качества.
- Перемотка, ускорение удержанием, восстановление позиции, полноэкранная альбомная ориентация.
- Исправлено отображение длинных сведений и получение фотографий актёров.
- Успешные CI, unit-тесты, подписанный APK, совпадение сертификата с 0.4.0–0.4.2, релиз 0.4.3 опубликован.

## Ещё не проверено на реальном устройстве

- Подключение к API конкретного зеркала, получение реального потока и начало воспроизведения.
- Совместимое обновление 0.4.2 → 0.4.3 без удаления данных.
- Озвучки, выбор серии и качество при длительном просмотре, звук, жесты и выход из полноэкранного режима.

Если источник не предоставляет доступный видеопоток, выводить конкретную ошибку. Не возвращать веб-страницу вместо плеера и не имитировать воспроизведение.
Не обходить DRM, платные ограничения и не копировать закрытый код сторонних APK.
Сохранять постоянный ключ подписи, applicationId и работающую архитектуру.
Не изменять Phantom VPN и серверы.

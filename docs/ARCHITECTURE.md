# Архитектура — предварительное решение

Статус: проектирование; зависимости и версии фиксировать при создании первой собираемой Android-версии.

## Клиент

- Kotlin + Jetpack Compose, адаптивная компоновка для планшета.
- AndroidX Media3 (ExoPlayer) для встроенного плеера.
- Room — локальная история, избранное, прогресс и пользовательские источники.
- DataStore — простые настройки.
- Сетевой слой с HTTPS, ограничением времени запросов и аккуратной обработкой ошибок.
- На первом этапе без собственного backend и без обязательного аккаунта.

## Изоляция источников

Интерфейс абстрактного Provider:
- проверка доступности адреса;
- получение метаданных/каталога только через разрешённую интеграцию;
- получение доступных вариантов воспроизведения;
- сообщение о состоянии входа, если источник поддерживает авторизацию.

Отделить провайдеры от UI и плеера. Не привязывать жизнеспособность приложения к одному зеркалу. Пользовательские адреса не кодировать в исходники и не включать в логи/аналитику.

## Безопасность

- Не передавать пароли через собственный сервер.
- Не хранить логины, сессионные cookies или токены в репозитории.
- Секреты на устройстве — только в защищённом локальном хранилище, если такая интеграция вообще понадобится.
- Не отключать проверку TLS ради «доступности зеркала».
- Доступ к источникам — только в рамках прав пользователя и правил провайдера; не реализовывать обход paywall или DRM.

## Проверка

Кодовая структура и CI появятся при реализации каркаса. До прохождения реальной сборки и тестов APK не объявлять готовым.

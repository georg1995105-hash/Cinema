# Кино — Android-приложение для планшета

Независимое приложение с русским интерфейсом, гостевым режимом, локальной историей и встроенным плеером. Название репозитория Cinema — техническое; название приложения на устройстве — «Кино».

## Версия 0.2.1 — каркас с нижней навигацией

**[Скачать APK напрямую](https://github.com/georg1995105-hash/Cinema/releases/download/v0.2.1/Kino-0.2.1.apk)**

[Страница релиза](https://github.com/georg1995105-hash/Cinema/releases/tag/v0.2.1) · [Успешная сборка и тесты](https://github.com/georg1995105-hash/Cinema/actions/runs/44086892761)

Реализовано:
- Компактная **нижняя навигация на планшете и телефоне**: Главная, Поиск, Разделы, Моё, Настройки.
- На главной только **одна строка разделов**, начиная с «Горячие», затем область каталога. Жанры находятся в отдельном разделе «Разделы».
- Нет большого информационного блока и искусственных карточек «Афиши».
- Гостевой режим, локальные история и избранное, запоминание места просмотра.
- Добавление, выбор, проверка доступности и удаление адресов зеркал.
- Плеер с настраиваемым шагом перемотки; прямые защищённые видеоссылки.
- Русские подписи во всех пользовательских разделах, настройки отдельно от каталога.

**Ещё не реализовано:** получение фильмов и сериалов из каталога, постеры, выбор озвучки и серий, авторизация в стороннем сервисе, автоматические обновления. Добавление зеркала пока не подключает каталог: нужен отдельный совместимый поставщик данных.

**Важно:** APK подписан отладочным сертификатом. Сборки, созданные разными запусками GitHub Actions, могут иметь разные подписи. Если предыдущая испытательная версия уже установлена, обновление поверх неё может не получиться; удаление старого приложения приведёт к потере его локальных данных. Постоянную подпись следует настроить до стабильных выпусков.

Проверки 17.11.2026: тесты и сборка APK на GitHub прошли; установка и просмотр на реальном планшете ещё не проверены.

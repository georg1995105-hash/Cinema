# CineTablet

Приватный проект Android-приложения для просмотра доступного пользователю видеоконтента. **Главный приоритет — удобство на планшете**, прежде всего в горизонтальной ориентации.

> Статус: создан репозиторий и техническое задание. Работающего Android-приложения, APK или интеграции с каталогом пока нет.

## Принципы

- **Гостевой режим — основной**: без обязательной регистрации и входа; история, избранное и позиция просмотра сохраняются локально.
- **Минимум настроек**: открыть каталог → выбрать видео → выбрать озвучку/качество (если доступны) → смотреть.
- **Настраиваемые источники/зеркала**: пользователь вручную добавляет адреса, хранящиеся на его устройстве; приложение не публикует их и не отправляет на сторонний сервер.
- **Быстрое переключение источников**: только между явно добавленными пользователем адресами, без обещаний обхода региональных или платных ограничений.
- **Плеер**: встроенный в приложении; поддержка внешнего плеера опциональна.
- **Аккаунт — по желанию**: интеграция с историей стороннего сервиса возможна только после проверки разрешённых способов авторизации и синхронизации.
- **Без сервера на первом этапе** и без телеметрии по умолчанию.

## Ориентир по интерфейсу

Тёмная тема, компактное вертикальное меню слева (главная, поиск, библиотека/история, профиль), сетка постеров и крупные зоны касания для планшета. Не копировать чужое приложение или бренд дословно.

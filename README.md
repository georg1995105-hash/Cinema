# Cinema — независимый Android-клиент для планшета

Гостевой режим, русский интерфейс, нижняя навигация, локальные зеркала, история и избранное. Репозиторий не связан с Phantom VPN.

## Возможности

- Сетка настоящих карточек из выбранного пользователем HTTPS-зеркала, разные подборки, кэш, прокрутка, настройка числа карточек.
- Поиск в выбранном зеркале по названию, голосовой ввод и локальные фильтры по доступным сведениям.
- **На телефоне**: большой постер и аккуратный выбор источника/озвучки перед просмотром. Отдельные секции актёров, режиссёров, связанных фильмов и подтверждённых связей, если источник их предоставляет.
- Экран фильма на планшете: крупный закреплённый постер слева, отдельно прокручиваемые сведения, актёры и франшиза справа. На телефоне — компактный вертикальный экран. Описание, основные сведения, избранное и подтверждённые связи. Ссылки актёров открывают их фильмографию, если зеркало её предоставляет.
- **Портреты актёров**: используются фотографии с карточки, а для нескольких отсутствующих портретов проверяются страницы персон на выбранном зеркале. Если фотографии там нет, выполняется ограниченный поиск через публичный Wikidata API, требующий точного имени и подтверждения актёрской/режиссёрской профессии. Используются только реальные изображения Commons P18 со ссылкой на исходную страницу файла. Неопознанные люди остаются без изображения.
- **Воспроизведение:** AndroidX Media3/ExoPlayer, альбомный полноэкранный запуск по умолчанию, компактное меню настроек **справа поверх видео**, без отдельного системного нижнего окна. Встроенный выбор качества, скорости, озвучки, сезонов, серий, масштаба и настоящих доступных `.vtt`/`.srt` субтитров. HLS определяется явно.
- Жесты: двойной тап для перемотки и удержание для временного ускорения. **Свайпы громкости и яркости удалены** по прямому требованию владельца.
- Сохранение позиции, сезона, серии и озвучки; **автоматический переход к следующему доступному эпизоду**, включая границу сезонов; позиция предыдущей серии не переносится на новую. Настройка автоперехода находится внутри плеера.
- «Все части франшизы» — данные из `b-post__partcontent_item`; при наличии отдельной `b-post__franchise_link_title` загружается страница франшизы в той же сессии зеркала. Порядок частей, годы и рейтинги подтверждаются исходной страницей, а не совпадением названий.
- **Нативный аккаунт и сеть**: собственная форма логина и пароля, выбор сохранённого зеркала, состояние сеанса и выход. Авторизация происходит непосредственно на выбранном HTTPS-зеркале по `/ajax/login/`, без сторонних прокси; пароль не сохраняется, а cookie принадлежат Android WebView. Регистрация требует отдельной страницы зеркала. **Нативной синхронизации истории пока нет**; гостевой режим сохраняется.
- **История и избранное** с настоящими постерами и названиями; прямое возобновление в Media3, а не попытка запустить URL страницы как MP4. Метаданные сохраняются при открытии фильма на устройстве.
- Управление зеркалами: выбор основного, проверка с измерением времени ответа и компактное меню действий.
- Автоматическая попытка следующего обычного видеосервера и другого свободно доступного качества, если зеркало предлагает альтернативы. Закрытые платные потоки не обходятся.
- Проверка обновлений и загрузка подписанного APK с отображением прогресса и контрольной проверкой.

## Проверки и ограничения

GitHub Actions выполняет модульные и Android-тесты. На эмуляторе проверяются поиск, постеры и метаданные карточек, запросы озвучек и серий в WebView, воспроизведение в Media3 и чтение локальных настроек прежней версии. Выпуск требует совпадения сертификата подписи и успешной установки поверх 0.4.17.

Наличие видео, постеров и возможность входа зависят от выбранного зеркала. Тесты используют контролируемые ответы и собственный тестовый ролик. Воспроизведение конкретного фильма и вход в аккаунт на устройстве пользователя требуют отдельной проверки.

При поиске фотографий отсутствующих на зеркале актёров передаётся **только публичное имя актёра** в Wikidata. Личные зеркала, ключи и cookies туда не отправляются. Фото берутся из Викисклада со ссылкой на исходную страницу файла и сведения о его лицензии.

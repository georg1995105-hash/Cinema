# Кино — Android-приложение для планшета

Независимое приложение с русским интерфейсом, гостевым режимом, локальной историей и встроенным плеером. Название репозитория Cinema — техническое; название приложения на устройстве — «Кино».

## Версия 0.4.0 — встроенный просмотр выбранного зеркала (в разработке)

**Последняя опубликованная испытательная сборка:** [0.3.1](https://github.com/georg1995105-hash/Cinema/releases/tag/v0.3.1). Следующую версию не публиковать с временной подписью.

[Страница релиза](https://github.com/georg1995105-hash/Cinema/releases/tag/v0.3.0) · [Успешная сборка и тесты](https://github.com/georg1995105-hash/Cinema/actions/runs/44096365574)

Реализовано:
- Компактная **нижняя навигация на планшете и телефоне**: Главная, Поиск, Разделы, Моё, Настройки.
- На главной **одна строка разделов**, начиная со «Смотрят сейчас», затем «Горячие». Справа компактный выбор типа контента. Отдельного пункта «Разделы» больше нет.
- Нет большого информационного блока и искусственных карточек «Афиши».
- В поиске: голосовой ввод через систему Android, разворачиваемые группы «Страны», «Жанры», «Годы» (страны по ISO, годы до пяти). Без источника каталога пока фильтруются только сохранённые видеоссылки по тексту.
- В настройках: количество карточек в ряду (применится к настоящей сетке после интеграции), скорость при удержании 2×–4×.
- Плеер: двойное нажатие слева/справа для перемотки, удержание для ускорения, резервный выбор декодера.
- Раздел «Обновления»: проверка GitHub Releases, уведомление, скачивание с процентами, проверка APK и установка через системный диалог Android.
- Гостевой режим, локальные история и избранное, запоминание места просмотра.
- Добавление, выбор, проверка доступности и удаление адресов зеркал.
- Плеер с настраиваемым шагом перемотки; прямые защищённые видеоссылки.
- Русские подписи во всех пользовательских разделах, настройки отдельно от каталога.

**Важное ограничение обновлений:** уведомления в приложении показываются только для стабильных (не испытательных) релизов, чтобы не предлагать несовместимые отладочные подписи. Постоянный ключ подписи ещё не настроен. Нельзя обещать обновление поверх предыдущих испытательных APK без совпадения сертификата.

**Ещё не реализовано:** получение фильмов и сериалов из каталога, постеры, выбор озвучки и серий, авторизация в стороннем сервисе, настоящий каталог; стабильная подпись обновлений; встроенный прокси VLESS/Hysteria2. Добавление зеркала пока не подключает каталог: нужен отдельный совместимый поставщик данных.

**Важно:** APK подписан отладочным сертификатом. Сборки, созданные разными запусками GitHub Actions, могут иметь разные подписи. Если предыдущая испытательная версия уже установлена, обновление поверх неё может не получиться; удаление старого приложения приведёт к потере его локальных данных. Постоянную подпись следует настроить до стабильных выпусков.

Проверки 17.11.2026: тесты и сборка APK на GitHub прошли, файл опубликован в релизе и подтверждён SHA-256; установка, работа распознавания речи и управление плеером на реальном планшете ещё не проверены.

Исследование необязательного модуля [«Сеть и прокси»](docs/NETWORK_MODULE.md) — без добавления второго системного VPN.

## Проверка зеркала и подпись 0.4.0

Добавлен встроенный гостевой браузер выбранного пользователем HTTPS-зеркала. Зеркало открывается с главного экрана или из настроек источников. Это временный режим для проверки реального доступа к сайту на планшете; **ещё не нативный каталог**, и серверные ограничения сайта не обходятся.

Для совместимых обновлений подключается постоянный сертификат: см. [инструкцию подписи](docs/SIGNING.md). Пока ключ не добавлен в GitHub Actions и релиз не проверен, новой устанавливаемой сборки не будет.

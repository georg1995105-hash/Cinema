## Возможности

- Сетка настоящих карточек из выбранного пользователем HTTPS-зеркала, разные подборки, кэш, прокрутка, настройка числа карточек.
- Поиск в выбранном зеркале по названию, голосовой ввод и локальные фильтры по доступным сведениям.
- Экран фильма: описание, основные сведения, избранное, актёры и рекомендации. Ссылки актёров открывают их фильмографию, если зеркало её предоставляет.
- **Портреты актёров**: сначала проверяется собственная страница актёра на выбранном зеркале. Если фотографии там нет, выполняется ограниченный поиск через публичный Wikidata API, требующий точного имени и подтверждения актёрской/режиссёрской профессии. Используются только реальные изображения Commons P18 со ссылкой на исходную страницу файла. Неопознанные люди остаются без изображения.
- **Воспроизведение:** AndroidX Media3/ExoPlayer, альбомный полноэкранный запуск по умолчанию, управление непосредственно поверх видео и скрытие панелей. Встроенное меню качества, скорости, озвучки, сезонов, серий, масштаба изображения и доступных субтитров.
- Жесты: двойной тап для перемотки, удержание для временного ускорения, свайп слева для яркости окна, справа для громкости медиа. При выходе яркость окна восстанавливается.
- Сохранение позиции просмотра, проверка обновлений и загрузка подписанного APK с отображением прогресса и контрольной проверкой.

## Проверено и ограничения

Автоматические тесты, сборка и проверка цифровой подписи **успешны**. Итоговый APK скачан из артефакта CI, проверен по SHA-256 и опубликован в Releases.

**Реальный запуск версии 0.4.6 на телефоне/планшете пользователя ещё не подтверждён.** Проверить альбомный режим, взаимодействие с настройками, сохранение позиции и реальные фотографии актёров. Наличие фото зависит от профилей зеркала и Wikidata; не каждый человек имеет достоверное публичное изображение. Если видеоисточник возвращает рекламу или Premium-заставку, приложение не может автоматически заменить её недоступным фильмом. Платные ограничения и DRM не обходятся.

При поиске фотографий отсутствующих на зеркале актёров передаётся **только публичное имя актёра** в Wikidata. Личные зеркала, ключи и cookies туда не отправляются. Фото берутся из Викисклада со ссылкой на исходную страницу файла и сведения о его лицензии.

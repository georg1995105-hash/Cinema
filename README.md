# Кино — независимый Android-клиент для планшета

## Возможности

- Сетка настоящих карточек из выбранного пользователем HTTPS-зеркала, разные подборки, кэш, прокрутка, настройка числа карточек.
- Поиск в выбранном зеркале по названию, голосовой ввод и локальные фильтры по доступным сведениям.
- Экран фильма на планшете: крупный закреплённый постер слева, отдельно прокручиваемые сведения, актёры и франшиза справа. На телефоне — компактный вертикальный экран. Описание, основные сведения, избранное и рекомендации. Ссылки актёров открывают их фильмографию, если зеркало её предоставляет.
- **Портреты актёров**: сначала проверяется собственная страница актёра на выбранном зеркале. Если фотографии там нет, выполняется ограниченный поиск через публичный Wikidata API, требующий точного имени и подтверждения актёрской/режиссёрской профессии. Используются только реальные изображения Commons P18 со ссылкой на исходную страницу файла. Неопознанные люди остаются без изображения.
- **Воспроизведение:** AndroidX Media3/ExoPlayer, альбомный полноэкранный запуск по умолчанию, компактное меню настроек **внутри самого видео**, без отдельного системного нижнего окна. Встроенный выбор качества, скорости, озвучки, сезонов, серий, масштаба и настоящих доступных `.vtt`/`.srt` субтитров. HLS определяется явно.
- Жесты: двойной тап для перемотки и удержание для временного ускорения. **Свайпы громкости и яркости удалены** по прямому требованию владельца.
- Сохранение позиции, сезона, серии и озвучки; **автоматический переход к следующему доступному эпизоду**, включая границу сезонов; позиция предыдущей серии не переносится на новую. Настройка автоперехода находится внутри плеера.
- «Все части франшизы» — данные из `b-post__partcontent_item`; при наличии отдельной `b-post__franchise_link_title` загружается страница франшизы в той же сессии зеркала. Порядок частей, годы и рейтинги подтверждаются исходной страницей, а не совпадением названий.
- Необязательный вход на сайт выбранного зеркала для использования своего аккаунта. **Нативной синхронизации профиля пока нет**, гостевой режим остаётся по умолчанию.
- Автоматическая попытка следующего обычного видеосервера, если зеркало предлагает альтернативы. Закрытые платные потоки не обходятся.
- Проверка обновлений и загрузка подписанного APK с отображением прогресса и контрольной проверкой.

## Проверено и ограничения

Автоматические тесты, сборка и проверка цифровой подписи **успешны**. Итоговый APK скачан из артефакта CI, проверен по SHA-256 и опубликован в Releases.

**Реальный запуск версии 0.4.8 на телефоне/планшете пользователя ещё не подтверждён.** В первую очередь проверить автовоспроизведение следующей серии, сохранение сезона/озвучки, подключение зеркала, возможные части франшизы, вход через сайт и отсутствие свайпов яркости/громкости. Наличие фото зависит от профилей зеркала и Wikidata; не каждый человек имеет достоверное публичное изображение. Если видеоисточник возвращает рекламу или Premium-заставку, приложение не может автоматически заменить её недоступным фильмом. Платные ограничения и DRM не обходятся.

При поиске фотографий отсутствующих на зеркале актёров передаётся **только публичное имя актёра** в Wikidata. Личные зеркала, ключи и cookies туда не отправляются. Фото берутся из Викисклада со ссылкой на исходную страницу файла и сведения о его лицензии.

# Cinema

Независимое Android-приложение для планшета: простой интерфейс, гостевой режим, локальная история и встроенный видеоплеер.

## Статус — прототип 0.1.0

**Код Android-приложения создан, тесты и сборка прошли GitHub Actions 17.11.2026.**
Проверенная сборка: [Android debug APK #44081770354](https://github.com/georg1995105-hash/Cinema/actions/runs/44081770354).

Для скачивания откройте страницу сборки → раздел **Artifacts** → `cinema-debug-apk`. В ZIP находится `app-debug.apk`.

Это **тестовый APK** с отладочной подписью. На планшете и с реальными источниками воспроизведение ещё не проверено. При переходе к постоянной подписи может потребоваться переустановка.

### Что есть в коде

- Адаптивный тёмный интерфейс с боковым меню для планшета.
- Гостевой режим без обязательной регистрации.
- Встроенный AndroidX Media3/ExoPlayer для прямых HTTPS-видеоссылок (MP4/HLS).
- Локальная история и позиция воспроизведения, сохранение пользовательских HTTPS-адресов.
- Ручная HTTP-проверка доступности добавленных адресов.
- Автоматизированная сборка Debug APK и unit-тесты в GitHub Actions.

### Чего ещё нет

- Интеграции с каталогом HDRezka либо другим каталогом.
- Получения доступных потоков, выбора озвучки, сезонов и серий.
- Авторизации или синхронизации истории с внешним сервисом.
- Подтверждённой работы на реальном планшете и стабильной подписи для обновлений.

Сохранение адреса источника **не означает** автоматически работающую интеграцию с ним.
Не реализованы обход DRM, платных ограничений или прав доступа.

## Технологии

Kotlin, Jetpack Compose, AndroidX Media3, локальное хранилище. Код написан независимо; сторонний мод APK **не включён** в репозиторий.

# Lite TV — экспериментальная фиксация горизонтальной ориентации

Отдельный эксперимент на ветке `experiment/lite-tv-landscape-20261121`. **Не относится к исходному Android-клиенту Cinema и не должен попадать в main.**

## Исходный APK (передан владельцем, не хранится в публичном репозитории)

- Android package: `limehd.ru.lite`
- Version: `5.3.1`, versionCode `638`
- minSdkVersion: `26`
- targetSdkVersion: `36`
- Главная активность: `limehd.ru.ctv.MainActivity`
- Уже задано `screenOrientation=landscape (0)`.
- Внутри MainActivity уже есть `android.window.PROPERTY_COMPAT_ALLOW_RESTRICTED_RESIZABILITY=true`.
- В основном модуле приложения (`classes7.dex`) обнаружены ссылки на `getRequestedOrientation`, но не обнаружен прямой вызов `setRequestedOrientation`.
- APK содержит стороннюю модифицированную подпись; оригинальный сертификат для пересборки недоступен.

## Гипотеза

Android 16 (API 36) может игнорировать ограничения ориентации на больших дисплеях (sw >= 600dp), если приложение ориентировано на API 36; приложение уже использует предусмотренный системой opt-out. Возможно дополнительное переопределение прошивкой или режимом многооконности. Без воспроизведения на устройстве нельзя считать первопричину доказанной.

Документация: https://developer.android.com/about/versions/16/behavior-changes-16

## Экспериментальный APK (собран локально, не опубликован в GitHub)

Изменён **только** `targetSdkVersion: 36 -> 35` в двоичном AndroidManifest.xml. Содержимое всех остальных файлов APK неизменно (сравнено побайтово после распаковки); удалены прежние подписи и добавлена новая подпись APK Signature Scheme v2 (RSA-3072 / SHA-256).

**Не проверено на устройстве**: установка, старт, вращение во время просмотра ТВ и работа авторизации/оплаты/обновлений. Android API 35 меняет не только политику ориентации — потому тест не предназначен для распространения клиентам.

## Приёмка

1. Установить на тестовое устройство после резервного копирования данных; подпись отличается от установленного мода, обновление поверх него может быть недоступно.
2. Запустить в вертикальном положении — приложение должно открыть горизонтальный экран.
3. Повернуть устройство на 90°, 180°, 270° и убедиться, что интерфейс остаётся в одном фиксированном ландшафтном положении.
4. Проверить каталог, ТВ-каналы, fullscreen video, выход из плеера и возвращение, фон/возврат, Wi-Fi/мобильную сеть.
5. Если проблема остаётся, снять точные параметры устройства (Android, sw dp, модель, режим многооконности) и не вносить новые изменения наугад.

Никакой код, APK или ресурсы Cinema в эксперименте не изменялись. Никакого PR в main.
